# Seiva landing page
- `npm install` e `npm run dev` para editar; `npm run build` gera a pasta `dist` para publicar.
- Todo o conteúdo fica em `src/content.js`. Procure por `[TROCAR]`.
- Logo: coloque `logo.png` em `public/` e ajuste `site.logo` em `content.js` (hoje há um logo provisório em SVG).
- Formulário: preencha `form.endpoint` em `content.js` (Formspree, Getform etc.).
- Imagem para compartilhamento (Open Graph): coloque `og.png` (1200x630) em `public/`.
